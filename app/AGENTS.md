## Agent skills

### Issue tracker

Issues, specs, and the wayfinder map live as GitHub issues in `securityvisions/router-app`. Use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `CONTEXT.md` + ADRs in `docs/adr/`. See `docs/agents/domain.md`.
