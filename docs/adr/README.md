# Architecture Decision Records

Decisions that shape the home-network system are recorded here as ADRs, one file per decision, numbered sequentially:

- `0001-<slug>.md`, `0002-<slug>.md`, …

Each ADR states the context, the decision, and the consequences. Read the ADRs that touch the area you're working in before making changes (see `docs/agents/domain.md`). Create new ADRs lazily when a real decision gets resolved — don't front-load them.
