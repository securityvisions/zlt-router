# AX3000T Feature Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a prioritized suite of 8 high-leverage performance, gaming, privacy, and remote access capabilities on the clean OpenWrt 25.12.5 AX3000T router without risking memory exhaustion, boot loops, or network disruption.

**Architecture:** Layer native kernel optimizations (`kmod-tcp-bbr`, `wed_enable`), wireless security upgrades (`sae-mixed`), gaming NAT daemons (`miniupnpd-nftables`), local ad-blocking (`adblock-fast`), and network isolation (`XI-Guest`) onto the verified OpenWrt 25.12.5 baseline (`192.168.1.1`). Every change is modular, reversible, and validated with automated checks.

**Tech Stack:** OpenWrt 25.12.5 (`apk` package manager), Linux 6.12.94 kernel, MediaTek MT7981B / MT7976 Wi-Fi 6, `nftables` / `firewall4`, `dnsmasq`, `hostapd`, `sysctl`.

**Spec:** `.scratch/ax3000t-features/spec.md`

## Global Constraints

- **Zero Automated Reboots:** Under no circumstances should any script or daemon issue an automated `reboot`.
- **RAM Footprint Cap:** Total background RAM usage for all added services must remain <25 MB (guaranteeing >75 MB headroom).
- **Overlay Storage Cap:** Total flash storage on `/overlay` must not exceed 15 MB (preserving >18 MB free).
- **Zero Internet Disruption:** Changes must be applied hot or via reload; LAN DHCP and Wi-Fi client sessions must not be dropped.
- **Rollback Safety:** Baseline snapshot `C:\Users\Public\axtftp\backup\ax3000t-resilience-final.tar.gz` is preserved.

### Task 1: Kernel TCP BBR Congestion Control (Ticket 01)

**Files:**
- Target on Router: `/etc/sysctl.d/15-bbr.conf`
- Package on Router: `kmod-tcp-bbr`

**Interfaces:**
- Consumes: Linux 6.12 kernel module infrastructure.
- Produces: Default TCP socket congestion control set to `bbr` with `fq_codel` packet scheduler.

- [ ] **Step 1: Install kmod-tcp-bbr package**

Run via SSH on AX3000T:
```bash
apk add kmod-tcp-bbr
```
Expected output: `Installing kmod-tcp-bbr... OK`

- [ ] **Step 2: Create persistent sysctl configuration**

Write to `/etc/sysctl.d/15-bbr.conf`:
```ini
net.core.default_qdisc = fq_codel
net.ipv4.tcp_congestion_control = bbr
```

- [ ] **Step 3: Load configuration and verify active algorithm**

Run on AX3000T:
```bash
sysctl -p /etc/sysctl.d/15-bbr.conf
sysctl net.ipv4.tcp_congestion_control
```
Expected output: `net.ipv4.tcp_congestion_control = bbr`

- [ ] **Step 4: Verify through-router speed & latency**

Run from laptop:
```bash
curl.exe -s --noproxy '*' --interface 192.168.1.223 -m 15 -o /dev/null -w "Throughput: %{speed_download} B/s in %{time_total}s\n" "https://speed.cloudflare.com/__down?bytes=15000000"
```
Expected output: Clean transfer with low latency and zero stalling.

- [ ] **Step 5: Mark Ticket 01 resolved**

Update `.scratch/ax3000t-features/issues/01-tcp-bbr.md` status to `resolved`.

### Task 6: Isolated Guest & Smart Home Wi-Fi (Ticket 06)

**Files:**
- Target on Router: `/etc/config/network`, `/etc/config/wireless`, `/etc/config/dhcp`, `/etc/config/firewall`

**Interfaces:**
- Consumes: 2.4GHz radio virtual interface.
- Produces: Isolated `XI-Guest` SSID on `192.168.3.1/24` with no access to private LAN.

- [ ] **Step 1: Configure guest bridge and network interface**

Add `guest` interface in `/etc/config/network` (`ipaddr 192.168.3.1/24`).

- [ ] **Step 2: Configure guest DHCP server**

Add `guest` pool in `/etc/config/dhcp` (range `192.168.3.100 - 192.168.3.200`).

- [ ] **Step 3: Configure guest firewall zone with strict LAN isolation**

Add `guest` zone in `/etc/config/firewall`:
- `input=REJECT`, `output=ACCEPT`, `forward=REJECT`.
- Forwarding `guest -> wan` allowed.
- Forwarding `guest -> lan` strictly blocked.
- Allow DHCP (udp 67) and DNS (port 53) to router only.

- [ ] **Step 4: Add XI-Guest SSID in /etc/config/wireless**

Configure `XI-Guest` on `radio0` (2.4GHz) with `isolate='1'`.

- [ ] **Step 5: Reload services and verify isolation**

Verify `XI-Guest` broadcasts, leases `192.168.3.x`, and cannot ping `192.168.1.1` or access LuCI.

- [ ] **Step 6: Mark Ticket 06 resolved**

Update `.scratch/ax3000t-features/issues/06-guest-iot-wifi.md` status to `resolved`.
