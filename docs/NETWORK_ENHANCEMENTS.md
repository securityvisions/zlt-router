# Network Enhancements

Three additional capabilities deployed on the router: **DNS ad-blocking**, **completed SQM**, and the **Iran timezone** fix.

## DNS ad-blocking

- **Package**: `adblock` + `luci-app-adblock` (~0.8 MB storage).
- **How**: feeds are downloaded, merged into a blocklist (~164k domains), and loaded into dnsmasq via its include directory. Blocked domains answer **NXDOMAIN**; normal domains resolve normally.
- **Feeds** (deliberately lean to bound RAM): `adguard` + `yoyo` + `disconnect`. The larger default set (~320k domains) drove dnsmasq to ~31 MB RAM; the lean set keeps it at **~15 MB**, respecting the router's memory.
- **Runtime**: blocklist is built in RAM (`/tmp`) and rebuilt on boot; the service is enabled at boot (`S30adblock`).
- **Honest limits**: blocks web ads/trackers at DNS level; it cannot block YouTube/Instagram/TikTok in-app ads (they share servers with content).
- **Verification**: `nslookup doubleclick.net 127.0.0.1` → NXDOMAIN; `www.google.com` → resolves.

## SQM (Smart Queue Management)

- **Package**: `sqm-scripts` (already present); configured via `uci`.
- **Config**: CAKE on the WAN, both directions:
  - download **35 Mbps** (was unset/0 — downlink was unshaped before)
  - upload **10 Mbps** (was 13 Mbps)
- **Rates were measured**, not guessed: live WAN tests gave ~33–41 Mbps down / ~10 Mbps up; rates are set at ~85–90% of measured for shaping headroom.
- **Verified**: `tc qdisc show` shows `cake` on both the WAN device (upload) and its ingress device (download).
- **Honest limit**: the router sits behind the ISP's device (double NAT), so shaping relocates the queue to this router where CAKE can manage it — a mitigation for latency spikes under load, not a fix for upstream bufferbloat.

## Iran timezone

- **Before**: the router clock was UTC, so every cron schedule fired 3.5 h off Iran time (the "09:00" Friday reminder fired at 12:30 Iran; the "21:00" daily report fired at 01:00 Iran).
- **Fix**: system timezone → `Asia/Tehran` (`IRST-3:30`, no DST since 2022); `/etc/localtime` regenerated by the system init; crond restarted.
- **Verified**: `date` shows IRST; a live cron tick fired at Iran time (e.g., 01:58 IRST).
- **Now**: all schedules fire at Iran-local times — balance 07:00, usage 21:30, snapshot 23:55, monthly 1st 07:00, Friday reminder 09:00 Friday, monitor every 15 min.

## Friday-discount reminder

- `0 9 * * 5` — every **Friday 09:00 Iran**, the bot sends: "🟢 It's Friday — 40% off Samantel packages today!" plus the current balance headline.
- Toggleable from the bot: `/fridayremind on|off` (flag in `/etc/billing.conf`).
- Honest note: buy renewals on Fridays to save 40% — the reminder exists specifically to prompt this.
